Docker Volume Persistence Project




📌 Project Overview
This project demonstrates Docker data persistence using Docker Volumes. I created my own Docker image, pushed it to Docker Hub, created a Docker volume, and verified that application data remains available even after deleting and recreating the container.



🚀 Technologies Used
Docker
Docker Hub
Docker Volumes
Linux


🛠️ Steps Performed
Created a custom Docker image.
Tested the image locally.
Pushed the image to Docker Hub.
Created a Docker volume.
Ran a container using the volume.
Added and verified data inside the container.
Deleted the container.
Created a new container using the same volume.
Verified that the data was still available.




📚 Concepts Learned
Docker Images
Docker Containers
Docker Hub
Docker Volumes
Data Persistence
Container Lifecycle




🎯 Outcome
Successfully demonstrated persistent storage in Docker using volumes. Even after deleting the container, the application data remained safe because it was stored in a Docker volume.
